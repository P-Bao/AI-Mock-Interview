# AI-Mock-Interview
AI Voice Mock Interview là một web application sử dụng trí tuệ nhân tạo để mô phỏng buổi phỏng vấn thực tế hoàn toàn bằng giọng nói, dành cho sinh viên chuẩn bị bước vào thị trường lao động

## Deprecated

`evaluation-module` đã được gộp vào `cv-module`. API evaluation chính hiện nằm trong `cv-module/backend` tại route `/api/evaluations` và hỗ trợ dùng `cv_session_id` để lấy Knowledge Graph context từ kết quả phân tích CV.
